## What it does

`main.py` (Python 3, standard library only, no network) writes
one final text message to `/output/entry.txt` — the last text a
phone sends at one percent battery, in the phone's own voice:

> I've been at 1% for 41 hours. I just wanted to see how long you'd ignore me.

The message is 76 characters long. The phone speaks for itself:
it has been sitting at one percent for 41 hours, and the twist
lands in the final words — it was never dying, it was testing
how long its owner would ignore it. One sentence, one twist at
the end, no low-battery pun, no human narrator explains the
joke for it. The number is the joke's spine: a phone at 1%
for 41 hours is absurd, and the confession makes it personal.
The phone is petty, patient, and done waiting — and it chose
its last 1% to say so.

## How to run

```sh
python3 main.py
```

## Output

Writes one text message (76 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
